# 电话汉语 학습장 — chinese.study.kang88.io

전화중국어 수업(맛있는 비즈니스 중국어 LEVEL 4) 기록을 모아 보는 정적 사이트.
중국교육센터 일일강사평 메일을 IMAP로 자동 수집한 데이터가 원본입니다.

- **대시보드** — 전체 진도, 공식 출석 달력 (2026-04 개강 ~ )
- **수업 기록** — 날짜별 어법·문장 + 한국어 번역, 월 필터·검색
- **단어장** — 누적 단어, 한자·병음·뜻 검색 + 플래시카드 퀴즈
- **교정 노트** — 강사가 바로잡아 준 표현 모음 (✗ → ◯)

## 디자인
Material 3에서 영감을 받은 밝은 테마. 블루(#0b57d0), 상태별 색상, 둥근 카드와 Roboto/Noto Sans KR 타이포그래피를 사용합니다. 한자는 Noto Sans SC이며, 모바일에서는 하단 메뉴로 이동합니다. 키보드 탐색, 모달 초점 유지, 동작 줄이기 설정을 지원합니다.

## 구조
순수 정적 사이트 (빌드 없음): `index.html` + `styles.css` + `app.js` + `data.js`(수집 데이터). 디자인 토큰은 `styles.css` 상단 `:root`에 모여 있습니다.

## 데이터 형식 (`data.js`)
회차는 수강권을 넘어 **누적**으로 셉니다. 첫 수강권(2026-04-07 ~ 10-30)은 110회로 마감했고, 재등록한 수강권(2026-11-10 ~ 2027-05-03, 120회)의 메일상 k회는 `110 + k`회입니다.

| 이름 | 내용 |
|------|------|
| `PROGRESS` | `done`·`att` 누적 출석 수 (= `CAL` 의 출석일 수), `total` 전체 회차 (지금 230 = 110 + 120), `start` 첫 개강일, `end` 현재 수강권 종료 예정일 (= `TERMS` 마지막 줄 `end`), `updated` 최신 기록일, `abs`·`cancel`·`pp`·`rp` 결석·휴강·일반연기·정규연기 일수 |
| `TERMS` | 수강권마다 한 줄 `{ start, end, first }`. `first` = 그 수강권 1회의 누적 회차 (메일상 회차 = `n − first + 1`) |
| `CAL` | 달마다 한 항목, 오래된 달부터. `key: "YYYY-MM"`, `name: "2026년 11월"`, `blanks` 1일의 요일(일=0), `days` 날 수, `start` 그 달에 시작한 수강권의 개강일(있을 때만), `att: {일: 누적 회차}`, `abs`·`cancel`·`pp`·`rp` 날짜 배열 |
| `LESSONS` | 최신순. `date` 수업 기록일 `YYYY-MM-DD`, `day` 요일, `n` 누적 회차 (`CAL` 출석과 1:1), `theme`, `items` (`{zh, ko, py?, gr?}` 또는 교정 `{fix: {bad, good}, ko}`), `words` (`"决心 juéxīn 결심 …"` 처럼 **한자 표제어로 시작**, 첫 공백 앞이 굵게 표시됨) |
| `VOCAB` | 최신순 `["YYYY-MM-DD", 중국어, 병음, 뜻]`, 같은 단어는 첫 등장일에 한 번 |

- **진도 %는 저장하지 않습니다.** 화면이 `Math.round(n × 100 ÷ PROGRESS.total)` 로 계산합니다 (예: 110회·111회 = 48%). 모든 화면이 같은 누적 기준입니다.
- `LESSONS.date` 는 수업 기록일이라 공식 출석일(`CAL`)이나 메일 수신일과 항상 같지는 않습니다 (7~8월 일부는 1~6일 늦음). 기록일이 출석일보다 앞서면 테스트가 실패합니다. 월별 수업 기록 수는 출석 수와 다를 수 있고, 단어 기록 수는 반복 학습한 단어를 포함합니다.

## 화면 규칙
- 월 필터·달력·날짜 스트립은 `"YYYY-MM"` 키로 찾으므로 2026-04 와 2027-04 가 섞이지 않습니다.
- `CAL` 이 한 해 안이면 월 칩은 `4월`, 단어장 날짜는 `11-10` 처럼 짧게, 두 해 이상에 걸치면 `2026년 4월`, `2026-11-10` 처럼 연도를 붙입니다.
- `TERMS` 의 모든 개강일에 달력 `개강` 배지가 붙고, 그 달 월 칩에 `(개강)` 이 붙습니다 (2026-04-07 첫 개강, 2026-11-10 재등록).
- 대시보드 문장은 `TERMS` 마지막 줄(현재 수강권)의 시작일과 종료 예정일을 보여 줍니다.
- 검색은 성조·대소문자·ü(v)·공백·`'`·`-` 를 무시합니다 (`liugan`, `liu gan`, `LIUGAN` → liúgǎn). 단, 한두 글자 영문(`AI` 등)은 성조를 무시하지 않고 글자 그대로(대소문자만 무시) 찾습니다 — 성조를 접으면 ài·zài 같은 음절까지 걸리기 때문입니다. 한글·한자는 그대로 비교합니다. `2026-11-10` 처럼 날짜만 입력하면 그날 기록만 보여 줍니다 (달력 → 수업 기록 연결도 이 방식).
- 상단 검색은 모든 월의 **수업 기록**을 검색합니다. 수업 화면의 검색은 선택한 월 안에서 검색하고, 단어장 검색은 별도로 동작합니다. 달력에서 수업을 열면 회차로 연결하므로 기록일과 출석일이 달라도 같은 수업을 볼 수 있습니다.
- 플래시카드는 섞은 순서대로 모든 단어를 한 번씩 낸 뒤 다시 섞고, 같은 단어가 연달아 나오지 않습니다.

## 추가하는 방법
- **수업 1회**: `LESSONS` 맨 위에 항목 추가 (`n = TERMS 의 first + 메일 회차 − 1`, `pct` 없음) → 공식 출석일의 `CAL.att` 에 `일: n` → `PROGRESS` 의 `done`·`att`·`updated` (상태가 생기면 `abs` 등도) → 새 단어는 `VOCAB` 맨 위에 연도까지 적은 날짜로.
- **새 달**: `CAL` 끝에 `{ name: "2026년 12월", key: "2026-12", blanks, days, att: {}, abs: [], cancel: [], pp: [], rp: [] }` 를 추가합니다. `blanks`·`days` 는 직접 세지 말고 계산합니다:
  `node -e 'const [y,m]=[2026,12];console.log(new Date(Date.UTC(y,m-1,1)).getUTCDay(), new Date(Date.UTC(y,m,0)).getUTCDate())'`
- **새 수강권**: `TERMS` 에 `{ start, end, first }` 한 줄 (`first` = 지금까지 누적 출석 수 + 1), 개강일이 있는 달 `CAL` 항목에 `start: 일`, `PROGRESS.total` 에 새 수강권 회수를 더하고 `PROGRESS.end` 를 새 종료일로 바꿉니다. 휴강·연기로 종료일이 바뀌면 `TERMS` 마지막 줄 `end` 와 `PROGRESS.end` 를 함께 고칩니다.
- **새 해**: 따로 할 일이 없습니다. 키에 연도가 들어 있으니 `CAL` 에 `"2027-01"` 달을 이어 붙이면 되고, 월 칩·단어장 날짜에 연도가 자동으로 붙습니다.

## 확인 방법

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열거나 정적 웹 서버로 실행합니다. Node.js 18 이상에서 아래 검사로 검색·모달·퀴즈 동작과 데이터 정합성(달력 키·요일, 수강권 회차, 기록일 ≥ 출석일, 단어 날짜 등)을 확인합니다. 데이터를 고친 뒤에는 반드시 실행합니다.

```sh
node --check app.js
node --check data.js
node --test tests/*.test.cjs
```

화면 변경 후에는 320px 모바일, 태블릿, 데스크톱에서 4개 메뉴를 확인합니다. 월 선택 후 상단 검색, 달력 → 수업 기록, 결과 없는 검색의 초기화, 모달의 Tab/Shift+Tab/Escape, 플래시카드 뜻 보기와 다음 단어를 함께 점검합니다.

## 배포
Vercel — 이 저장소의 `main` 브랜치에 푸시하면 자동 재배포됩니다.
도메인: https://chinese.study.kang88.io (kang88.io는 Vercel DNS + 와일드카드라 별도 DNS 설정 불필요)

- 커밋할 때는 `git add data.js` 처럼 파일 이름을 적습니다. `git add .` 은 쓰지 않습니다.
- `.gitignore` 는 `.omc/`·`.gstack/`·`._*`(macOS 메타데이터)·`.DS_Store` 를 저장소에서 빼고, `.vercelignore` 는 그 파일들과 `tests/`·`README.md`·`QA_REPORT.md` 를 배포에서 뺍니다.
- `<meta name="robots" content="noindex, nofollow">` 와 `vercel.json` 의 `X-Robots-Tag: noindex` 헤더로 검색엔진 노출을 막습니다. `robots.txt` 로 크롤링을 막지 않는 것은 일부러입니다: 막으면 검색엔진이 noindex 표시를 읽지 못해, 다른 곳에 링크가 있을 때 주소가 검색 결과에 남을 수 있습니다. 접근 제한은 아니라서 주소를 아는 사람과 공개 GitHub 저장소에서는 내용을 볼 수 있습니다.
