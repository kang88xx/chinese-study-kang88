# 电话汉语 학습장 — chinese.study.kang88.io

전화중국어 수업(맛있는 비즈니스 중국어 LEVEL 4) 기록을 모아 보는 정적 사이트.
중국교육센터 일일강사평 메일을 IMAP로 자동 수집한 데이터가 원본입니다.

- **대시보드** — 전체 진도, 공식 출석 달력 (2026-04 개강 ~ )
- **수업 기록** — 날짜별 어법·문장 + 한국어 번역, 월 필터·검색
- **단어장** — 누적 단어, 한자·병음·뜻 검색 + 플래시카드 퀴즈
- **교정 노트** — 강사가 바로잡아 준 표현 모음 (✗ → ◯)

## 디자인
Material 3에서 영감을 받은 밝은 테마. 블루(#0b57d0), 상태별 색상, 둥근 카드와 Roboto/Noto Sans KR 타이포그래피를 사용합니다. 한자는 Noto Sans SC이며, 모바일에서는 하단 메뉴로 이동합니다. 키보드 탐색, 모달 초점 유지, 동작 줄이기 설정을 지원합니다.

## 구조
순수 정적 사이트 (빌드 없음): `index.html` + `styles.css` + `app.js` + `data.js`(수집 데이터).
새 수업이 추가되면 `data.js`의 `PROGRESS` / `CAL` / `LESSONS` / `VOCAB`에 항목을 추가하고 푸시하면 됩니다. 디자인 토큰은 `styles.css` 상단 `:root`에 모여 있습니다.

상단 검색은 모든 월의 **수업 기록**을 검색합니다. 수업 화면의 검색은 선택한 월 안에서 검색하고, 단어장 검색은 별도로 동작합니다. 달력에서 수업을 열면 회차로 연결하므로 기록일과 출석일이 달라도 같은 수업을 볼 수 있습니다.

`LESSONS.date`는 수업 기록일입니다. 공식 출석일(`CAL`)이나 메일 수신일과 항상 같지는 않습니다. 월별 수업 기록 수는 출석 수와 다를 수 있고, 단어 기록 수는 반복 학습한 단어를 포함합니다. 현재 데이터 모델은 2026년 한 수강권 기준입니다. 여러 연도를 합칠 때는 달력 키를 `YYYY-MM`로 확장해야 합니다.

## 확인 방법

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열거나 정적 웹 서버로 실행합니다. Node.js 18 이상에서 아래 검사로 검색·모달·퀴즈 동작과 데이터 정합성을 확인할 수 있습니다.

```sh
node --check app.js
node --check data.js
node --test tests/*.test.cjs
```

화면 변경 후에는 320px 모바일, 태블릿, 데스크톱에서 4개 메뉴를 확인합니다. 월 선택 후 상단 검색, 달력 → 수업 기록, 결과 없는 검색의 초기화, 모달의 Tab/Shift+Tab/Escape, 플래시카드 뜻 보기와 다음 단어를 함께 점검합니다.
